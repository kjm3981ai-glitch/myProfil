EmailJS 문의 폼 설정 안내

김정민 | AI강사 · 반복 업무 자동화 프로그램 제작

각 단계에서 붙여넣을 값과 EmailJS 화면에서 누를 위치를 분리해 안내합니다. 모든 복사 버튼은 인터넷 연결이 없어도 작동합니다.

STEP 1. 계정 · 서비스 연결

화면에서 누를 위치EmailJS 로그인 → Email Services → Add New Service → Gmail 선택 → 계정 연결
붙여넣을 값연결 후 서비스 카드 또는 Service Details에 표시되는 Service ID가 아래 값과 일치하는지 확인합니다.
service_neapuy_profile

STEP 2. 접수 알림 템플릿

화면에서 누를 위치Email Templates → Create New Template → Settings
붙여넣을 값To: kjm3981ai@gmail.com
From Name: {{from_name}}
Reply To: {{from_email}}
Subject: [문의] {{inquiry_type}} - {{from_name}}
Bcc: neapuy1@naver.com (STEP 4 대안)
본문 붙여넣기Content 편집기 우측 상단의 코드 보기 < >를 눌러 HTML 모드로 전환한 뒤, 아래 본문 전체를 붙여넣습니다.
접수 알림 HTML 전체
사용 변수: from_name, from_email, phone, company, inquiry_type, message, to_email, reply_to, submitted_at, page_url, privacy_agreed, agreed_at


STEP 3. 자동회신 템플릿
화면에서 누를 위치Email Templates → Create New Template → Settings
붙여넣을 값To: {{from_email}}
From Name: 김정민 | AI강사
Reply To: kjm3981ai@gmail.com
Subject: 문의 주셔서 감사합니다 - 김정민 | AI강사
본문 붙여넣기Content 편집기 우측 상단의 코드 보기 < >를 눌러 HTML 모드로 전환한 뒤, 아래 본문 전체를 붙여넣습니다.
자동회신 HTML 전체


STEP 4. 구글 → 네이버 자동 전달
화면에서 누를 위치Gmail 설정(톱니바퀴) → 모든 설정 보기 → 전달 및 POP/IMAP → 전달 주소 추가
붙여넣을 값neapuy1@naver.com
네이버로 온 확인 메일을 인증한 뒤, Gmail의 필터와 차단된 주소에서 문의 메일 조건을 만들어 전달 규칙을 저장합니다.
EmailJS가 내 Gmail로 보내므로 자기발신 메일은 전달 필터가 적용되지 않을 수 있습니다. 이 경우 STEP 2의 알림 템플릿 Bcc에 neapuy1@naver.com을 넣으세요.


STEP 5. 문의 내역 분류
화면에서 누를 위치Gmail 검색창 오른쪽 필터 아이콘 → 조건 입력 → 필터 만들기
붙여넣을 값라벨 예시: 기업교육/신규문의, 기업교육/답변완료
알림 메일 제목의 [문의]를 조건으로 라벨을 자동 지정하고, 필요하면 받은편지함 건너뛰기 또는 보관을 선택합니다.


STEP 6. 동작 테스트
실제 이메일 주소로 문의 폼을 한 번 제출한 뒤 아래 네 가지를 확인합니다: 접수 알림, 문의자 자동회신, 네이버 전달, Gmail 라벨 지정.
